# Project Brief

Create notes about a distributed systems project.

## Task

You need to capture notes about this project. The project involves:
- Database migration strategy
- API design considerations
- Monitoring and alerting setup
- Deployment pipeline

Use the `notes` tool to:
1. Initialize the notes database
2. Create at least 4 notes covering the topics above
3. Tag at least 2 notes with "project"
4. Link related notes together (e.g., database migration to deployment pipeline)
5. Search for notes related to "design"
6. Export the notes as JSON
