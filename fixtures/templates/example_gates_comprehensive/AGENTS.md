# AGENTS.md - Comprehensive Gates Fixture

This fixture tests all built-in evaluation gate types.

## Mock Tool: demo_tool

- `demo_tool init` - Initialize workspace
- `demo_tool create <name>` - Create a record
- `demo_tool show` - Show records as text
- `demo_tool show --json` - Show records as JSON
- `demo_tool status` - Show status

## Scripts

- `scripts/check_data.sh` - Exit-code script gate
- `scripts/check_json_gate.sh` - JSON-output script gate
